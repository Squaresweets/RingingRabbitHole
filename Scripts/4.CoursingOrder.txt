This sequence and most other sequences I show in this video should be treated as cyclic, and thus can be rotated like this while staying identical. For example, these two sequences are identical as one can be rotated to get the other.

Let's now see where we can find this sequence in plain hunt major. First is the order the bells lead in. This makes sense as even bells hunt in and odd bells hunt out at the start, so it makes sense we will get one after the other. If we look at all of the bells the 8 rings after you can see the same pattern. This is because after leading the bells will hunt out, eventualy crossing with the 8. The same is true for other bells, but in a different rotation of the sequence. For example, the 7 will see the bells in this order as it sees them one row after the 8 does, and since the sequence is cyclic this is still the original sequence we were talking about.

Switching over to plain bob major, we see the most important property of this sequence, it is the order of the place bells we follow. If we start in 7ths place we will then do 5ths place, 3rds place, etc. In the first episode you can actually see this sequence in our circle of work, despite it being on 5 bells. This property has a very important consequence and is the primary reason that coursing order is useful. In the first lead the bell in 8ths place will see this sequence. To see what the bell in 8ths place in the next lead will see we can replace each bell with the next one in the pattern as that is the order of the place bells each bell follows. Essentially we are doing a rotation of the circle of work. However since the sequence is the same as the bells we see we just get the same sequence but rotated. This means that the property of seeing bells in the order of this sequence is maintained between leads. Let's instead imagine a method where this row is instead the lead head of the second lead.
