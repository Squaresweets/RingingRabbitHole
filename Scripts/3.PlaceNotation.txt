This is all of plain bob doubles. You can imagine that to share methods this would be quite a lot of information to share, so lets think of ways to compress it down. We found out in the first episode that the movement of the bells in each lead is the same, so to recreate the whole method we only need the first lead. This grid view is better, but we can do better. The grid view only shows how the bells move in a lead, it does not specify bell numbers. To store this pattern we can split it into all of the changes and encode each of them.
Looking at each change, notice how they are made up of crosses and lines. Each line represents a bell making a place, and if a bell isn't making a place it is swapping positions with another bell. Looking at all possible changes on 5 bells, you can see that this pattern holds, we only have crosses and straight lines. An intuiative way to store a change is thus to store which bells make places. As a side tangent, there are sometimes inconsistencies about leaving some numbers out in the notation. For example, in a minimus method, if we had the notation “1”, there must be some other bell which also makes a place, as there are 3 other bells. Some sources may correct this to 12 and some to 14. For example, the single in stedman doubles has the notation “45”; however, this is short for “ 345” not “145”. Be careful with this, and when in doubt, write the notation out in full to avoid ambiguity.
