Calling:
Types of columns:
Calling positions (BWH):
    Can have multiple columns of the same position. Read left to right top to bottom.
    Left to right top to bottom, whenever you get a call replace it with the top of the column then that call
    sV–M–W–IsWsF–H–VsB–F
    If more than 3 with different positions, grouped together into a= or whatever
    Number based calls, work with how many leads since the last course head. A course head occurs either when a lead head matches the coursehead mask(s) or when a cell contains a colon.
    Course head is blue, parthead is green
    Brackets at each end are length of each course, goes onto next row when new course!!

Calling positions (123)
Parts:
    ±2[–-,-] Replace with second one in part 2
    +3|6[s] Include in parts 3 and 6
    - is omit

Methods:
    Half lead splices
    Define every lead, read top to bottom, can only have one methods column
    Starting place lets you shift method left and right, filling in the rest with places
    Rotate by x rotates all place notation back towards the start.
    Start row no. only effects the first lead and starts from a later row (done after rotation). Theres also a seperate start row number(?)

Calls:
    There are defualt calls, but can add custom
    Changes replaced is how many are overwritten, doesn't have to be the same length as the notation (trim)
    You can make your own calling positions using the right side of the able and defining an observation mask.
    Lead position name is liked to call, where it checks for the observation mask.


Blocks:
    Can only be used after being defined. Cannot be redefined.
    Can have multiple blocks columns
