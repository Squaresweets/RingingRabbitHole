Types of columns:
Calling positions (BWH):
    Can have multiple columns of the same position. Read left to right top to bottom.
    Left to right top to bottom, whenever you get a call replace it with the top of the column then that call
    sV–M–W–IsWsF–H–VsB–F
    If more than 3 with different positions, grouped together into a= or whatever
    Number based calls, work with how many leads since the last course head. A course head occurs either when a lead head matches the coursehead mask(s) or when a cell contains a colon.
    Course head is blue, parthead is green
    Brackets at each end are length of each course, goes onto next row when new course!!

Calling positions (123)
Parts:
    ±2[–-,-] Replace with second one in part 2
    +3|6[s] Include in parts 3 and 6
    - is omit

Methods:
    Half lead splices
    Define every lead, read top to bottom
    Starting place lets you shift method left and right, filling in the rest with places
    Rotate by x rotates all place notation back towards the start.
    Start row no. only effects the first lead and starts from a later row (done after rotation). Theres also a seperate start row number(?)

Calls:
    There are defualt calls, but can add custom
    Changes replaced is how many are overwritten, doesn't have to be the same length as the notation (trim)
    You can make your own calling positions using the right side of the able and defining an observation mask.
    Lead position name is liked to call, where it checks for the observation mask.


Blocks:
    Can only be used after being defined. Cannot be redefined.
    Can have multiple blocks columns

But what about the special columns. Methods columns are all concatonated left to right top to bottom and define what method each lead is using the menmonic given with the method. A fullstop signifies a call. #(Q,S) notation can be used to repeat all inside until the end.
Blocks, go from first to last instance of a letter. Can have multiple columns. After defining you can use it, but position doesn't matter it takes up a whole row in teh output and just fills it out.

That's the basics for creating compositions, but you can customise it further with custom calls and calling positions.
When defining a method mnemonic you don't only give it a method you can also add extra information, so you could have two mneomics refuring to the same method but with different modifiers. Starting place can shift the line left or right for compositions on higher stages. Rotate by rotates all of the changes in the place notation. Start row no. makes it so that when you sp-lice to that method (or at the very start) you start at a different row within the method, with the missing start at the end. Lead ends are in the normal places. Length lets you cut off place notation. Note that you can do start position seperatly.
Lead position row no. and lead position name are more complicated. You can define multiple lead positions per method and use that to to define custom calling positions. For example you can add a call t which occurs at the half lead position.
The mnemonic heading and observation mask fields let you define custom calling positions. These positions can be used for default calls but not for other custom calls without redefining them. The observation mask uses the same notation as the coursehead mask. Can also override default calls to get a different observation bell for that method if you fancy it.
