-- Intro sequence -- 

This is a method known as plain bob doubles, one of the first methods you learn. When you look at a method this is the most common visualisation. Each number represents that numbered bell ringing, and the method can be read from left to right top to bottom. Certain numbers are replaced with lines to better visualise how that bell moves, each different colour represents a different bell. All methods start with rounds, so we can tell that the red line represents the treble and the blue line represents the 5.
A couple of important things to note are that the method starts and ends with rounds, there are no repeated rows, and that between each row every bell can only move a maximum of one position.

The method is split up into sections called "leads", with each lead being seperated by a rule-off. Something very important to note is that the pattern that the bells make within each lead is identical. If we ignore the bell numbers and just use lines to show the path each bell makes and then overlay each lead you can see that they are identical. This sort of visualisation is also very common.

You can see from this "grid view" that for the majority of each lead the bells are following a simple pattern of hunting out to the back by moving to the right each time, lying by staying in that position for two ros, and then hunting in to the front to lead. If we continue this pattern you can see that we get back to rounds at the next row, however in plain bob doubles we do something different and instead have one bell make seconds, two bells dodge and one bell make 4 blows at the back, so after our first lead our bells are in this order. This row is known as the "lead head" and this row is known as the "lead end". A change represents how the bells "change" between two rows, and this change is known as the lead end change.

After the first lead we can see we have the bells in this order, with this row being the lead head of the next lead. Putting the leads next to eachother, notice how where the first lead started with rounds the second leads starts with this different row. This means that after the first lead the 4 is now doing the same as what the 5 did in the first lead, the 2 is doing what the 4 did and so on. We say that the 4 is doing 5s work (?) or is 5s place bell (?). If we put this into a graph we can see that it is a cyclic relationship, each time whichever bell did 4s work in one lead will do 5s work in the next lead.

Lets look at what work each bell needs to do in the first lead, the 2 dodges 3-4 down, the 3 makes second, the 5 dodges 3-4 up and the 4 does 4 blows behind. After the first lead which bell is doing which work rotates round, so now, for example, the 5 is making second instead of the 2. The magical thing is that we can repeat this rotation to get the place bells for the next lead, and the next, and the next! However, you can see that after 4 rotations we are back to where we started, and so we are back at rounds. The number of rotations required to get back to rounds is where we get the number of leads from.

The reason that this rotation trick works is because of something known as permutations. After the first lead we have shuffled the bells around in a very specific way to get the next lead head. Since we know that the pattern the bells take is the same between every lead we know that to get to the next lead head we can just apply the exact same shuffle. This forms a cycle of which place bell each bell is in, and since the length of the cycle is 4, after applying the permutation 4 times we get back to where we started, rounds!

Notice how there is one bell that we haven't mentioned yet, the treble stays in the same place after each lead and so no other bell can start doing its work and the treble can't start doing any other bells work. If a bell does this, it is known as a hunt bell and this is what makes it so simple to ring, it just does the same thing each lead. If instead we had a method where there are no hunt bells we would have a method with 5 leads and 5 different pieces of work to learn. Conversely, if we had two hunt bells we would only have 3 leads as there are only 3 bells which can rotate their work.

The upside of having lead ends work like this is that you can ring using place bells. If you know the work for each bell in each lead its easy to start from a different bell and to deal with calls. You can envision that when you ring on a differnet bell you are just starting somewhere else along the method, going until you get back to where you started (?).
